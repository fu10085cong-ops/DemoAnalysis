# R06 研究分支：四类行为与"能不能跑"

状态：设计中（2026-10-21 产品负责人定方向）
主线不变：R03 的激进 / 保守（大类）及已有结果全部保留。本分支在同一批窗口上**另加**一个细分标签和几列局势变量，不改主线的标签。

## 行为：四类 + 看不出

| | 动了（换位置） | 没动（留在原地） |
|---|---|---|
| 激进（在找人打） | 主动寻求对枪：往敌人方向走、拉新枪线 | 被动寻求对枪：留在原地，暴露在敌人来路上，准星对着来路 |
| 保守（在避免对枪） | 主动保守：往更安全的地方走，如给烟后撤、转点 | 被动保守：留在原地，但躲在掩体或烟后、不暴露，拖时间 |

- 大类与主线一致：主动 / 被动保守都是保守，主动 / 被动寻求对枪都是激进
- 打标签：AI（MiMo 文字版 + 看图版）按五个选项判，人工盲审抽检；程序不写这四类的规则

## 局势："能不能跑"（不进行为标签）

"能不能跑"是行为**之前**的局势，单独成列，用来分层（研究原则 7）。全部在**交战结束那一刻**测量，只用他和队友当时可能知道的信息（已知威胁 + 可能威胁，`research/threat.py`）。产品负责人选的四个信号，口径是初稿，阈值放 `config/research.toml`：

1. **位置角色**：已有列 `role`（A 主防 / B 主防 / 中路 CT 侧 / 后方 / 接触区）
2. **退路是否被看着**：从他的位置沿导航路线往 CT 出生点方向走前 N 单位（初稿 400），路上有多少比例的地面格子能被已知威胁看到（烟挡住的不算）
3. **敌我人数**：他周围一定距离内（初稿 1500）的已知 T 人数；沿导航路线一定距离内（初稿 800）活着的 CT 队友人数
4. **离掩体的距离**：沿导航路线到最近的"已知威胁都看不到"的地面格子的距离（用 `potential.py` 的地面格子与格子间视线矩阵）

先记四列原始数值，不合成一个"能跑 / 跑不了"。人工复核时顺带标"能跑 / 跑不了"，再看哪几个信号、什么阈值和人工判断最一致。
