# 问题目录（v2，按实测结果回头审核）

状态：**草稿**。审核通过后由任务单实现为代码（`features/problems.py`），阈值进 `config/default.toml` 或职业基准文件。已实现的问题见 features/problems.py。

## 用途与原则

结构化报告中，AI 的每条结论都必须归到这里的某一类问题。程序检查该瞬间的数据是否满足这一类的**前提条件**，不满足就退回修改。

- 前提条件只是"可以这样说"的**必要条件**，不代表一定是失误。轻重由 AI 结合情境判断，"职业参考"一栏帮助它判断：职业也经常这样的，就不是重点。
- **问题分两层：**
  - **通用问题**：与武器无关，所有武器都适用（站位、决策、道具、配合）。
  - **武器专项**：先覆盖 AK-47、M4A4、M4A1-S、AWP、USP-S、Glock-18、Desert Eagle 七把武器。其他武器（冲锋枪、霰弹枪、SSG 等）暂时只套用通用问题，以后再补。
- **枪法类问题的阈值按武器分别设定**：同一条"出枪慢"，AWP 和 Glock 的标准不同。
- **交火武器的认定**：目标玩家在这次交火中第一枪所用的武器；没开枪时，用事件发生时手持的武器。
- 阈值来源：ESL Pro League S24 的 15 张图（职业 150 人次）与 5E / 完美 23 场（路人 229 人次）的逐次交火统计（2026-10-15）。下文的"职业 / 路人"数字都出自这批数据。
- **正式阈值以 `src/cs2coach/baselines/pro_sample.json` 为准**（由 `scripts/build_baseline.py` 生成，任务 004）。下文表格是可行性验证时的统计，口径略有不同（例如交火次数没有计入未开枪的交火），数值与正式基准大体一致，仅供阅读。
- 标注 **〔待开发〕** 的问题需要新的检测，标注 **〔待核实〕** 的武器特性来自常识，实现前要用 demo 数据或游戏文件核实。

### 1.2 交火处理

| 编号 | 名称 | 适用 | 前提条件 | 职业参考 | 可靠度 |
|---|---|---|---|---|---|

### 1.4 只作背景，不能当作问题

（2026-10-15 依据实测频率新增：`turned_into_flash` 被对手闪中后被击杀、`weapon_not_ready` 拉栓期间交火，见文末"实测频率"。）

以下内容会出现在事实卡里，但不能单独作为一类问题提出，检查器会拒绝：

- **单独出现的"死时有道具没用"**：和战绩正相关（钱多、活得久的人身上道具也多）。
- **离队友远、孤立阵亡**：还没用回合胜负验证过。2026-10-16 产品负责人确认不列入问题目录（虽然已验证阵亡时离最近队友超过 1000 单位只有约 5% 被补回）；事实卡照常显示最近队友的距离。
- **对手先看见、首死、人数优势时阵亡**：这些是零和指标，只能结合具体情境说。
- **被队友闪死**：不是本人的问题。

## 实测频率与审核结论（2026-10-15）

用最新代码在路人 229 人次（4,924 回合，5E 15 场 + 完美 8 场）和职业 150 人次（3,090 回合，ESL Pro League S24 15 张图）上统计每类问题的命中频率（每 10 回合几次）：

| 问题 | 路人 | 职业 | 倍数 | 有此问题的人次（路人 / 职业） |
|---|---|---|---|---|
| 压枪差（单次交火） | 0.49 | 0.20 | 2.5 | 62% / 33% |
| 出枪慢 | 2.84 | 1.38 | 2.1 | 99% / 91% |
| 人数优势时冒进 | 0.15 | 0.08 | 1.9 | 27% / 14% |
| 身上有道具却直接拉出 | 0.28 | 0.15 | 1.9 | 45% / 31% |
| 准星没提前放好 | 2.30 | 1.62 | 1.4 | 98% / 95% |
| 开枪时没停稳 | 1.25 | 0.88 | 1.4 | 92% / 83% |
| 漏补枪 | 1.11 | 0.81 | 1.4 | 89% / 78% |
| 主动拉出撞上对手架点 | 0.72 | 0.56 | 1.3 | 77% / 65% |
| 拉栓期间交火 | 0.32 | 0.34 | 0.9 | 41% / 41% |
| 被对手闪中后被击杀 | 0.31 | 0.41 | 0.8 | 48% / 52% |
| 下包后带着火没用、沙鹰移动开枪、Glock 远距离、扫射时在移动 | ≤ 0.07 | | | 太少见 |

路人每人每场平均命中 21 条问题（不含亮点）。

**结论（产品负责人确认）：**

1. **单条命中不说明问题，要看频率**：报告的重点取"该玩家的频率明显高于职业"的问题，由程序计算频率对比（任务 008），AI 优先讲倍数最高的几类。
2. **`turned_into_flash`、`weapon_not_ready` 降为背景**：路人并不比职业多，前者主要反映对手的道具水平，后者多数是被迫的。事实卡照常显示。
3. **暂时停用、待校准**：`spray_while_moving`（几乎不触发）、`awp_unscoped_shot`（路人中 0 次）、整场的 `spray_control`（一场里同一发数段很难攒够 30 发）。
